# Concurrent-File-Search-Tool-using-C-and-pthread-library

🚀 Project Update: I’ve developed a custom grep-like tool for Linux, leveraging multithreading to significantly improve search performance.

🔍 This tool allows for concurrent text searching within the current directory and, with the -r flag, recursively through all subdirectories. It currently supports regular expression (regex) search patterns (e.g., TextToSearch*), making it flexible for various use cases.

🛠️ I'm actively working on adding support for additional options like case-insensitive search (-i) and other commonly used flags to enhance usability.

Excited to continue improving this tool and open to feedback or suggestions!
